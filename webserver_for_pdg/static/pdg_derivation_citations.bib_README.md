`pdg.bib` is used by `create_pdf_for_derivation` in `latex.py` for compiling PDFs with citations from .tex files generated by PDG. These citations are used in derivations.

`pdg.bib` is separate from <https://localhost/documentation/literature_review?referrer=documentation_overview> which has citations relevant to the PDG-as-a-project rather than specific derivations.
